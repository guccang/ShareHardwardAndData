# 局域共享 · Simple LAN Share 0.4.0

供同一使用者在多台 Windows 电脑之间快速同步文字/图片剪贴板、拖拽传文件。无需账号、固定服务器或共享码，不含键鼠控制。

## 开始使用

1. 在所有电脑上退出旧版（托盘右键 → **退出**），解压新版并运行 `SimpleLanShare.exe`。Windows x64 便携版自带 .NET，不需要管理员权限。
2. 软件启动后直接在托盘后台运行，自动发现局域网内运行本软件的电脑。**双击托盘图标打开窗口**。若 Windows 防火墙询问，请允许在当前**专用网络**上通信。
3. 首次连接时两端自动弹出确认窗口，显示电脑名称、IP 和同一个 **6 位校验码**。只需核对一致并点击**确认连接**，不需要输入或复制任何码。
4. 双方确认后开始共享并记住设备，下次启动自动连接。未确认、拒绝或超时的设备无法接收剪贴板和文件。误拒绝后，两端点击**重新配对**即可重试。
5. 在任意电脑复制文字或图片，其所有在线已配对电脑就能直接粘贴。连接时不会自动广播历史剪贴板；需要时点击**同步当前剪贴板**。
6. 在“文件发给”选择一台电脑或**全部在线电脑**，把文件拖入绿色区域，或点击区域多选文件。“已接收文件”中的文件可以拖到本地资源管理器，双击可定位文件。

**点击窗口关闭按钮或最小化，都会留在托盘继续共享。** 双击托盘图标恢复窗口；再次运行程序也会恢复已有窗口。只有托盘右键菜单的**退出**会结束程序。“停止共享”会保留程序但停止网络与传输。

接收目录默认为 `%USERPROFILE%\Downloads\SimpleLanShare`，可停止共享后更改。默认自动接收已配对设备的文件；关闭此选项后逐个确认。重名文件自动加序号，不覆盖原文件，不自动执行收到的程序。

## 开机后台运行

首次运行新版默认开启**开机自启动**：当前用户登录 Windows 后直接在托盘运行，自动连接已配对且在线的电脑，无需再次确认。可以在主窗口或托盘菜单取消“开机自启动”。手动运行程序同样默认后台启动；使用 `SimpleLanShare.exe --show` 可直接打开窗口。

启动项保存在当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，不需要管理员权限。请先把便携版放到固定目录再运行；移动目录或升级后运行一次新版会更新启动路径。删除软件前可先取消自启动。系统任务管理器禁用启动项后，需要在那里重新启用。

## 截图与共享

- 按 **Ctrl+Alt+A** 或点击托盘“截图”，拖动框选区域，松开左键即复制图片。支持多显示器桌面，按 **Esc** 或鼠标右键取消。
- 已开启剪贴板同步且连接成功时，截图自动同步给所有在线已配对电脑，可直接粘贴；关闭同步时仍可本机截图。
- 托盘“查看 / 保存上次截图”打开预览，**Ctrl+S** 保存 PNG，**Ctrl+C** 重新复制。上次截图仅保存在运行内存中，不自动落盘。
- 可在“截图快捷键”修改组合。快捷键被其他软件占用时会提示，仍可通过窗口或托盘菜单截图。
- 桌面捕获上限为 8000 万像素；截图跨电脑同步遵循下方图片传输限制，过大的图片可保存为文件再发送。混合 DPI、受保护视频与全屏应用的实际捕获效果需按设备验证。

截图交互参考 [guccang/screenshot](https://github.com/guccang/screenshot/tree/6a03cfcff7b523b00ac14dbe792bf30564eb7bc0) 的全局快捷键、框选、预览及保存流程，在本项目 .NET 8 架构中独立实现，未引入该项目的可执行文件。当前提供基础框选截图，不含标注或长截图。

## 矩形区域录屏

1. 点击主窗口**区域录屏**，或托盘右键 → **区域录屏…**。
2. 拖出矩形选区，松开左键，再选择 MP4 保存位置，即开始录制。框选时 Esc / 右键取消；取消保存也不会开始录制。
3. 录制时主窗口隐藏，托盘改用醒目图标，悬停显示时长。托盘右键 → **停止录屏并保存**，或打开主窗口点击**停止录屏**。
4. 点击**录屏文件**或托盘**打开上次录屏位置**定位视频，可把视频拖入原有投递区发给其他电脑。视频不会作为图片剪贴板自动广播。

输出为**无声 MP4（H.264），目标 20 fps，最大 1920×1080**。较大选区按比例缩小，奇数尺寸调整为偶数；性能不足时帧率下降，但时间戳保持实际速度。当前不录音、不单独叠加鼠标指针、不支持暂停续录。

点击窗口 X 仍在后台录制；托盘**退出**会先停止并封装视频。锁屏或显示器布局变化时停止保存，恢复后不自动录制。停止共享网络不影响本机录屏。录制期间不能同时框选截图。

使用 [Windows Media Foundation](https://learn.microsoft.com/en-us/windows/win32/medfound/using-the-sink-writer) 编码，无需安装 FFmpeg。Windows N 版需要启用媒体功能包。受保护的视频、锁屏桌面和部分独占全屏内容可能无法捕获。

写入期间在目标目录使用 `.recording-<随机标识>.mp4` 临时文件，封装成功才替换最终文件；录制失败不覆盖已有目标。强制结束进程或断电可能留下无法播放的临时文件，请正常停止录屏后再退出。

## 配对与设备管理

- 没有固定主机，各设备两两配对直连。三台设备首次使用需要完成三对确认，之后自动重连。
- “重新配对”清除本轮拒绝/超时结果，再次自动尝试连接；不会删除已信任设备。拒绝后不会持续弹窗打扰。
- “清除信任”移除本机记住的设备并暂停共享；下一次连接需要重新确认。
- 广播不可用时，输入对方窗口展示的 IPv4 地址，点击“连接 IP”，同样需要首次确认。手动模式请两两连接需要共享的设备。
- 建议所有设备升级到 **0.4.0**。与 0.2.0 / 0.3.0 使用相同协议 v2，保留已配对设备；不兼容更早的共享码协议。

## 能力与限制

| 功能 | 行为 |
| --- | --- |
| 多电脑 | 每台最多连接 16 台其他设备 |
| 文本 | Unicode，UTF-8 最大 1 MiB，不传 HTML/富文本 |
| 图片 | PNG 传输，最大 8 MiB、3200 万像素、单边 16000 像素 |
| 文件 | 双向、多目标，每批最多 128 个，单个最大 10 GiB；64 KiB 流式缓冲、SHA-256 校验 |
| 拖拽 | 资源管理器 → 软件投递区 → 对端接收目录；接收列表 → 本地资源管理器 |
| 文件夹 | 先压缩成 ZIP，再拖入发送 |
| 同时使用 | 按同一时刻操作一台电脑设计；多端同时复制时最后到达的剪贴板覆盖当前内容 |
| 网络中断 | 当前任务取消，发现可用时自动重连；不续传文件，不重放历史剪贴板 |
| 大文件期间 | 剪贴板与文件正文使用独立连接，不等待整个文件发送结束 |

不提供跨电脑屏幕边缘拖拽、剪贴板文件的自动上传、键鼠控制或云中转。请以普通用户运行，避免 Windows 拖拽权限隔离影响文件投递。

## 网络与存储

- TCP `42656`：双向 TLS 1.2/1.3。证书证明设备身份，首次双方确认后才建立业务通道；已信任设备按证书指纹校验，不凭名称识别。
- UDP `42657`：每 3 秒广播协议版本、设备证书指纹和端口，不广播数据正文或私钥。
- 配置位于 `%LOCALAPPDATA%\SimpleLanShare\settings.json`。本机证书私钥通过 Windows 当前用户 DPAPI 加密保存；信任列表只存指纹。换 Windows 用户、重置身份或证书变更后需重新确认。
- 没有云账号，不记录剪贴板正文。无法发现时检查专用网络、防火墙、Wi-Fi 客户端隔离或 VPN；可改用手动 IP。
- 文件校验完成前使用 `.lanshare-<标识>.partial` 临时名，正常断线会清理。强制结束进程或断电可能留下临时文件，确认没有传输时可手动删除。

## 图标

青绿色圆角底板、两张相连卡片和相反方向的箭头，表达数据双向共享。可编辑源文件为 `src/LanShare.App/Assets/app-icon.svg`；提供 512px PNG，以及 16/20/24/32/48/64/128/256px 多尺寸 ICO，已用于程序文件、窗口和托盘。

需要重新生成图标时运行 `scripts/build-icon.ps1`（Windows PowerShell，脚本已带 UTF-8 BOM）。图形以确定性矢量方式绘制，没有外部图片依赖。

## 构建和测试

Windows 上安装 .NET 8 SDK 或可构建 .NET 8 的更新 SDK：

```powershell
.\scripts\test.ps1
.\scripts\build.ps1
```

生成 `artifacts\SimpleLanShare-0.4.0-win-x64\SimpleLanShare.exe` 和同名 ZIP。首次构建需要下载微软运行时包，没有第三方 NuGet 依赖。已有缓存时可用 `scripts/build.ps1 -Offline` 完全离线发布；此模式不查询在线漏洞元数据。开发运行并打开窗口：

```powershell
dotnet run --project src\LanShare.App\LanShare.App.csproj -- --show
```

结构：`LanShare.Core` 为发现、身份确认、协议与传输，`LanShare.App` 为原生 Windows 界面与系统剪贴板，`tests/LanShare.Tests` 为真实 TCP/TLS 回环集成测试。参考提供的 LAN-Bridge 文档独立实现，未复用其源码或二进制。

本机已验证 59 项核心断言、37 项 Windows 自检、界面预览和合成视频的独立解码；真实桌面的多屏录制、长时间录制、重启登录、多台实体电脑的剪贴板粘贴和文件拖拽仍需实机验收。详情见 `VERIFICATION.md`。
