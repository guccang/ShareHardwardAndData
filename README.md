# 局域共享 · Simple LAN Share

一个面向同一使用者、多台 Windows 电脑的轻量共享工具。参考提供的 LAN-Bridge 0.6.16 说明文档中的局域网连接与文件传输思路独立实现，没有复用其二进制或源码。

本项目只共享**文字/图片剪贴板和文件**，不监听、控制或转发键盘鼠标。

## 直接使用

1. 将发布包解压到各台 Windows 10/11 x64 电脑，双击 `SimpleLanShare.exe`。便携包自带 .NET，不需要安装运行时，也不需要管理员权限。
2. 在第一台电脑复制自动生成的**共享码**，把同一个码填入其他电脑。共享码代表加入同一组的权限；请只交给自己的设备。
3. 各台点击**开启共享**。允许 Windows 防火墙在当前**专用网络**上通信。同一广播网段会自动发现并建立加密直连，通常需要数秒。
4. 自动发现不可用时，输入对方窗口展示的局域网 IPv4 地址，点击**连接 IP**。多台电脑需两两可达；手动模式下请连接各个需要互相共享的设备。
5. 在任意电脑复制文字或图片，其他在线电脑更新剪贴板，直接粘贴即可。刚连接时不会广播旧剪贴板；需要时点击**同步当前剪贴板**。
6. 在“文件发给”选择一台电脑或**全部在线电脑**，把文件拖入绿色区域。也可点击该区域多选文件。收到的文件保存在各自配置的接收目录，可在“已接收文件”页拖出到资源管理器，或双击定位文件。

默认接收目录：`%USERPROFILE%\Downloads\SimpleLanShare`。默认自动接收同组文件；取消“自动接收同组文件”后，每个文件需要确认，超时自动拒收。重名文件添加序号，不覆盖原文件。收到的程序不会自动执行。

最小化后在托盘运行；双击托盘图标恢复。关闭窗口或托盘“退出”会退出程序。“停止共享”会结束全部连接和进行中的传输。重启后保留共享码与设置，再点击“开启共享”加入。

## 功能与边界

| 功能 | 简化版行为 |
| --- | --- |
| 多电脑 | 设备两两直连，无固定主机；每台最多连接 16 台其他设备 |
| 文字剪贴板 | Unicode 文本，UTF-8 最大 1 MiB；不含富文本/HTML |
| 图片剪贴板 | PNG 传输，编码后最大 8 MiB、3200 万像素、单边不超过 16000 像素 |
| 同步方向 | 任意设备复制，发送到其所有在线对端；关闭同步后不发送也不写入本机剪贴板 |
| 文件传输 | 双向、多目标、每批最多 128 个文件、单文件最大 10 GiB；64 KiB 缓冲流式传输和 SHA-256 校验 |
| 文件拖拽 | 资源管理器 → 应用投递区 → 对端接收目录；接收列表 → 本地资源管理器 |
| 文件夹 | 暂不支持直接拖文件夹，请先压缩成 ZIP |
| 同时操作 | 按同一时刻使用一台电脑设计；多端同时复制时，最后到达的更新覆盖当前剪贴板，不合并冲突 |
| 网络中断 | 取消当前任务；发现仍可用时自动重新连接；不重放历史剪贴板，也不续传文件 |
| 大文件期间 | 剪贴板与文件正文使用独立连接，文件等待确认或传输不会占用剪贴板通道 |

不提供跨屏键鼠控制、把文件直接拖过另一台电脑屏幕边缘、资源管理器文件复制的自动上传、云中转、跨互联网连接或开机自启。管理员权限窗口可能受 Windows 拖拽权限限制，请以普通用户启动应用。

## 网络与存储

- TCP `42656`：经过共享码认证的 TLS 直连；控制/剪贴板和文件正文使用不同连接。
- UDP `42657`：IPv4 局域网发现，每 3 秒广播；仅包含协议版本、随机节点 ID、端口和共享组标记，不包含共享码或数据正文。
- 无法发现时检查共享码、Windows 专用网络、防火墙、Wi-Fi 客户端隔离和 VPN。跨 VLAN 或禁广播网络可手动 IP 连接。
- TLS 1.2/1.3 与 128 位随机共享码证明绑定临时证书及双端随机数；业务数据只在认证后传输。
- 设置位于 `%LOCALAPPDATA%\SimpleLanShare\settings.json`，共享码用 Windows 当前用户 DPAPI 加密。
- 不记录剪贴板正文，不建立键盘日志。活动列表只保存在进程内。
- 文件采用随机 `.lanshare-<标识>.partial` 临时名，完整校验后改名；正常断线会清理。系统断电或强制结束进程可能留下临时文件，可在确认没有传输时手动删除。

## 构建与验证

安装 .NET 8 SDK 或可构建 .NET 8 的更新 SDK，在 Windows PowerShell 执行：

```powershell
.\scripts\test.ps1
.\scripts\build.ps1
```

生成 `artifacts\SimpleLanShare-win-x64\SimpleLanShare.exe` 和 ZIP 分发包。首次构建需从 NuGet 获取微软运行时包；项目不使用第三方 NuGet 依赖。

开发时可执行：

```powershell
dotnet run --project src\LanShare.App\LanShare.App.csproj
```

结构：`src/LanShare.Core` 为发现、认证、协议与流式传输；`src/LanShare.App` 为 Windows 窗体、系统剪贴板、拖拽与配置；`tests/LanShare.Tests` 为不依赖测试框架的真实网络集成测试。

已在本机验证构建、三个实例的 TCP/TLS 网状连接、文本/PNG 字节传输、文件哈希、重名、空文件、拒收、断线清理、重连、UDP 发现、Windows 图片编解码、DPAPI 和发布包启动。**回环模拟不能代替多台真机验收**；真实网络防火墙、跨电脑剪贴板粘贴、实际文件拖入拖出和长时间运行仍需实机检查。详见 `VERIFICATION.md`。

Windows 剪贴板使用系统的 [AddClipboardFormatListener](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-addclipboardformatlistener) 通知和系统序号去重，避免把收到的剪贴板再次广播。
